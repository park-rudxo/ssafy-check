개인정보처리방침

SSAFY 출석 체크 알리미 (Chrome 확장 프로그램) · 시행일: 2026-08-11

"SSAFY 출석 체크 알리미"(이하 "본 확장 프로그램")는 SSAFY 교육생의 입실·퇴실 체크를 돕기 위한 Chrome 확장 프로그램입니다. 본 방침은 본 확장 프로그램이 어떤 정보를 다루는지, 그 정보를 어디에 저장하고 누구에게 전달하는지를 설명합니다.

1. 개발자가 수집하는 정보

없습니다. 본 확장 프로그램의 개발자는 서버를 운영하지 않으며, 사용자의 어떤 정보도 개발자에게 전송·수집·저장되지 않습니다.

2. 브라우저에 저장되는 정보

아래 정보는 모두 사용자의 브라우저 안(chrome.storage.local)에만 저장되며, 외부로 전송되지 않습니다.

  • 오늘 입실/퇴실 체크 버튼을 눌렀는지 여부 및 시각 (기기 로컬 판단용)
  • 사용자가 직접 등록한 휴무일 목록
  • Mattermost 알림 사용 여부, 사용자가 입력한 본인의 Mattermost 아이디 등 설정값
  • 확장 프로그램 업데이트 공지를 확인했는지 여부

이 데이터는 사용자가 확장 프로그램을 삭제하면 함께 삭제됩니다.

3. 외부로 전송되는 정보

전송 대상전송 정보목적조건
SSAFY 홈페이지 (edu.ssafy.com) 없음 (페이지 내용을 읽기만 함) 입실/퇴실 버튼 강조 표시, 서버 기록 시각 확인 사용자가 해당 사이트를 방문할 때만 동작
SSAFY Mattermost (meeting.ssafy.com) 입실/퇴실 상태를 요약한 텍스트 메시지와, 받는 사람으로 지정한 본인의 Mattermost 아이디 사용자 본인에게 개인 메시지(DM)로 출석 리마인더 전달 사용자가 설정 화면에서 본인의 Mattermost 아이디를 입력하고 기능을 켰을 때만 동작. 기본값은 꺼짐

Mattermost 연동은 사용자가 본인의 Mattermost 아이디를 직접 입력하고 기능을 켰을 때만 동작합니다. 메시지는 사용자의 브라우저에서 SSAFY Mattermost 서버로 직접 전송되며, 개발자의 서버를 거치지 않습니다. 전송에 쓰이는 Incoming Webhook 은 확장 프로그램에 포함된 공용 주소이므로 보낸 사람 이름은 그 웹훅 이름으로 표시되지만, 메시지가 도착하는 곳은 사용자가 입력한 본인 아이디의 개인 메시지(DM) 뿐입니다. 보내는 내용은 입실/퇴실 체크 여부와 시각뿐입니다.

4. 요청하는 권한과 사용 목적

권한사용 목적
alarms매일 08:50 / 17:50에 리마인더를 보내기 위한 타이머
notifications크롬 알림(입실/퇴실 리마인더)을 화면에 표시
storage위 2번 항목의 설정값을 브라우저에 로컬 저장
optional_host_permissions (meeting.ssafy.com)사용자가 Mattermost 알림을 켤 때만 요청되는 선택적 권한. 이 호스트 외에는 요청하지 않음

본 방침은 크롬 웹스토어에서 설치한 버전을 기준으로 합니다. GitHub 저장소에서 zip 을 내려받아 설치하는 배포본은 새 버전 공지를 확인하기 위해 GitHub 의 공개 릴리스 API(api.github.com)를 추가로 조회하며, 이때도 전송되는 사용자 정보는 없습니다. 웹스토어 버전은 크롬이 알아서 갱신하므로 이 조회를 하지 않고, 해당 권한도 요청하지 않습니다.

5. 제3자 제공

본 확장 프로그램은 어떠한 사용자 데이터도 광고, 분석, 또는 그 외 제3자에게 판매·공유·제공하지 않습니다.

6. 아동 개인정보

본 확장 프로그램은 SSAFY 교육생(성인)을 대상으로 하며, 만 14세 미만 아동을 대상으로 하지 않습니다.
